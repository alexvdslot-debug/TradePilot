# Add shares entry correction

The generic transaction form defaults to Deposit. A dedicated Add shares action now selects Buy, exposes the required share fields and focuses the ticker. Empty purchases describe the required fields. Insufficient cash explains how to record an actual earlier deposit or currency exchange; validation and accounting remain unchanged.

Lesson: a disabled action needs a specific explanation and a visible route to resolve its prerequisites. Existing holdings are recorded from actual executed transactions, without inventing balances or placing orders.
